# TaskFlow

Sistema simples de gestão de tarefas feito com Flask, HTML, CSS e JavaScript.

## Funcionalidades

- Criar tarefas
- Listar tarefas por estado
- Apagar tarefas sem recarregar a página usando fetch()
- Validação no frontend e backend
- Persistência em arquivo JSON
- Interface com sidebar e modal de confirmação

## Tecnologias

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- Docker

## Como rodar localmente

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
